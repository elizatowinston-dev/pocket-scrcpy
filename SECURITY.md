# Security Policy

## Responsible Use & Educational Scope

`scrcpy-android` is designed for personal device management, recovery of devices with broken screens, and educational research into Android display subsystems and remote debugging protocols.

- **Authorized Use Only:** Only connect to and control devices that you personally own or have explicit authorization to manage.
- **ADB Privileges:** ADB debugging grants complete control over the target operating system, including reading files, executing shell commands, and injecting simulated hardware inputs.
- **Key Safety:** Never share your private ADB keys or session pairing codes. Keys generated by the application remain securely stored in private application storage.

## Reporting a Vulnerability

If you discover a security vulnerability within `scrcpy-android`, please report it by opening a private GitHub Security Advisory or contacting the repository maintainers directly.
